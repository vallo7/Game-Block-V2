# Game Block

Game Block is a mobile solo puzzle game focused on satisfying gameplay,
clarity, mastery and replayability.

## Status

Phase 0 — Foundation

## Technology

- JavaScript
- Vite
- Capacitor
- Android

## Architecture

The project is being rebuilt from scratch.

The gameplay core must remain independent from:

- HTML
- Canvas
- DOM
- audio
- haptics
- advertising
- network
- mobile platforms
